# Gymcord League Rules Wizard

A single-page form that asks fantasy gymnastics league hosts about their rules and generates a copyable, Discord-formatted league announcement.

Open `index.html` directly in a browser — no build step, no dependencies.

## Deploying to GitHub Pages

1. Create a new repo on GitHub (public, so free Pages hosting works) and push this folder to it:
   ```bash
   git remote add origin https://github.com/<your-username>/<your-repo>.git
   git branch -M main
   git push -u origin main
   ```
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Set branch to `main` and folder to `/ (root)`, then **Save**.
5. GitHub will give you a URL like `https://<your-username>.github.io/<your-repo>/` within a minute or two — share that link for testing.
